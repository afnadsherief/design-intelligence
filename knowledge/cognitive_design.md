# Cognitive Design

**Source:** Nielsen Norman Group, Don Norman, Cognitive Psychology
**Last Updated:** 2026-08-07
**Status:** Reference document

---

## Mental Models
Users bring pre-existing expectations. Design aligns with or deliberately breaks these models.

## Cognitive Load
- **Intrinsic:** Content complexity — reduce via chunking
- **Extraneous:** Poor design — remove unnecessary
- **Germane:** Learning effort — optimize organization

## Attention & Perception
- Selective attention: make important elements stand out
- Inattentional blindness: don't rely on assumed visibility
- Change blindness: signal changes clearly

## Memory
- Recognition over recall
- Working memory: 7plus or minus 2 items
- Use familiar patterns

## Application

Cognitive principles are enforced via:
- **Component contracts** (limited variants)
- **Evaluation system** (hierarchy scoring)
- **Pattern library** (consistent patterns)
